How it works

Three moments, and you own none of them.

01 · pair
A one-time URI

Ghostlink mints a pairing topic and symmetric key, then renders it as a QR code or deep link. Extensions skip straight to the injected provider.

02 · propose
Permissions, in writing

You declare chains, methods and events. The wallet shows exactly that, the user picks which accounts to share, and nothing outside the proposal is grantable.

03 · sign
Sessions that survive reloads

One settled session, seven-day expiry, automatic relay reconnect. Every signature still needs its own in-wallet approval — no blanket allowances.

Why bother

Every Kaspa app is rewriting the same 2,000 lines.

Four wallets, four injected APIs, four sets of error codes, and a QR flow nobody wants to own. Ghostlink is that work, done once, in the open, with the session model wallets already ship.

In the box

Boring where it counts.

Typed end to end

Methods, events and errors are TypeScript unions. Bad chain ids and unsupported methods fail at compile time, not at the signing prompt.

Headless, then themed

Take the hooks and build your own modal, or drop in ours and retheme it with six CSS variables. No stylesheet fights.

Every failure has a screen

Rejected, expired, wrong chain, unsupported method, relay dropped. Each one is a real state with real copy, not a console warning.

Reconnects without asking

Sessions persist across reloads and restore on boot. Users approve once a week, not once a tab.
