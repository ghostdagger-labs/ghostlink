The mark

Two nodes, overlapping. The solid one is the app; the outlined one is the wallet — present, but never held. The overlap is the session.

Construction

Radius 6.4 on a 12-unit pitch, so the nodes overlap by exactly one sixth of a diameter. Stroke is one third of the radius. Never redraw by eye.

Wallet connections, solved once.

Ghostlink is a TypeScript SDK for pairing Kaspa wallets with apps. It speaks the WalletConnect v2 session model over a CAIP-2 kaspa namespace, so wallets that already ship WalletConnect need an adapter, not a rewrite.

Sessions, not connections
Long-lived sessions with explicit namespaces, expiry and re-auth — the WalletConnect v2 shape Kaspa wallets already understand.
Typed end to end
Every method, event and error is a TypeScript union. Wrong chain ids and unsupported methods fail at compile time.
Headless, then themed
Bring your own markup, or drop in the prebuilt modal and retheme it with six CSS variables.
Adapters, not rewrites
Wallets map their existing signer onto four methods. Reference adapters for Kasware, Kastle and KSPR ship in the repo.
